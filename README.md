## Сервис для подбора рекомендаций для пользователя
Сервис использует МЛ-модель для подбора рекомендованных постов для пользователя. Используется подход - контентная рекомендация. 
Модель учитывает данные пользователя, данные поста, содержание поста (Векторизация текста с помощью it-idf), история любимых постов пользователя 
(Усреденения it-idf по всем любимым постам), а также дополнительные фичи (Временные, подход bag of centroid, svd матрицы it-idf).

В репозитории есть ноутбук с предобработкой данных, созданием фичей, обучением и валидацией модели (**Путь: "Feature engeering and fit model\Recommendation model.ipynb"**)

Финальные результаты качества модели по метрики roc-auc:
* На треине: 0.720
* На тесте: 0.7

Средняя время ответа сервиса = ~0.5 сек.
